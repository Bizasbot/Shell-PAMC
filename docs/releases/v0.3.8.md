# Oh My CPA v0.3.8

Esta versión mantiene visibles las actualizaciones de cuotas fallidas, añade un registro gestionado de complementos de Oh My CPA a la tienda de complementos y guía a los endpoints de OpenCode para que adjunten el encabezado de sesión que necesitan.

## Registro gestionado de complementos de Oh My CPA

- La tienda de complementos incluye el registro publicado de Oh My CPA como una fuente gestionada, habilitada por defecto. Los operadores ya no necesitan agregar su dirección manualmente.
- Las entradas de ese registro están marcadas, se denominan `Oh My CPA` y se muestran antes que otros registros, manteniendo el orden propio de cada registro. Instalar uno aún requiere confirmar el ID del complemento.
- La fuente se reconcilia durante las lecturas de la tienda y los guardados de configuración. La dirección gestionada nunca se convierte en un duplicado editable, y el interruptor de configuración de Oh My CPA es la forma admitida para deshabilitarla.
- Una reparación que no se pueda respaldar o auditar hace que la operación falle en lugar de escribir una configuración no verificada.

## Guía de sesiones de OpenCode

- Cuando la URL base de un proveedor utiliza exactamente el host `opencode.ai`, el editor muestra un aviso en línea junto a la dirección en cada ruta de canal.
- Un solo clic agrega `x-opencode-session: $CPA-SESSION-ID` al borrador y muestra los encabezados personalizados (Custom Headers). CPA expande el valor para la solicitud; Guardar lo persiste.
- Las filas de encabezados duplicadas o en conflicto se resuelven de forma segura: un duplicado en blanco no puede sobrescribir un ID configurado, y dos ID diferentes requieren la revisión del operador en lugar de una elección automática.

## Estado de actualización de cuotas

- Una actualización fallida ahora permanece visible después de que se cierra su notificación de error (toast). La fila nombra el último intento y su motivo, conserva la última lectura utilizable y ofrece una acción de actualización para esa credencial.
- Los errores de autenticación marcan la credencial para su reautorización. Otros errores muestran una lectura obsoleta (stale) cuando existe una, o un estado de lectura fallida cuando nunca se ha almacenado ninguna lectura utilizable.
- Las lecturas saludables o de advertencia que superan su propio límite de restablecimiento anunciado se informan como obsoletas en lugar de saludables. El resumen separa las instantáneas obsoletas de las lecturas saludables actuales.
- Las marcas de tiempo de los intentos utilizan el reloj de cuotas y se capturan antes de que comience la lectura, por lo que las lecturas superpuestas conservan el intento que comenzó último.

## Notas de actualización

- Haga una copia de seguridad de `.env` y del directorio o volumen de datos antes de actualizar; siga `docs/ops/sqlite-operations.md`. La migración 044 añade `quota_refresh_attempts`; el esquema avanza a `044_quota_refresh_attempts.sql`.
- La fuente de complementos gestionados se agrega a `plugins.store-sources` de CPA cuando el interruptor está activado. Las protecciones de revisión existentes, las copias de seguridad de la configuración y los requisitos de auditoría siguen vigentes. Desactive la fuente desde la Configuración de Oh My CPA cuando no la desee.
- La línea base general de la API de gestión de CPA v8.0.0 de OMC se mantiene sin cambios. La fuente de complementos y los controles de cuotas no modifican el enrutamiento de solicitudes.
- Compose continúa usando `latest` por defecto. Después de su publicación, fije esta versión con `wiziscool/oh-my-cpa:v0.3.8` o `wiziscool/oh-my-cpa:0.3.8`.
